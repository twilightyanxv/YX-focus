# 注意力星球 · 项目上下文

> 最后更新：2026-08-17

## 1. 概述 / 技术栈
面向 5-12 岁儿童的游戏化专注力训练 PWA。家长建家庭、添加/管理孩子、发奖励；孩子训练赚星币、商店消费。
Vue3+TS+Vite+Pinia+VueRouter4(Hash)+Supabase+CSS动画+Canvas+vite-plugin-pwa。Node v24 Windows。构建验证：`npx vue-tsc --noEmit` + `npx vite build`。**打包产物输出到 `docs/` 文件夹**（`vite.config.ts` 配置 `build.outDir:'docs'`，便于静态托管如 GitHub Pages；PWA sw.js 等随之生成）。

## 3. 认证 / 角色
- **家长**：OTP 注册（1 封邮件/家庭）→ verifyOtp → 设密码。OTP 框 8 位兼容 6/8；Supabase 需关 Confirm email。
- **孩子**：家长面板输入昵称（≤10 字，双端校验）→ Edge Function 创建；随机邮箱 `child_xxx@tmp.attentionplanet`+随机密码存 `profiles.child_password`；0 邮件。孩子注册入口已注释。

## 4. Edge Function：create-child-user
`supabase/functions/create-child-user/index.ts`，esm.sh 导入，CORS+OPTIONS，家长 JWT 验证（不 --no-verify-jwt），需 Secret `SUPABASE_SERVICE_ROLE_KEY`。

- 成绩落库：`game_type='whack'`, score/accuracy/reaction_time_ms

## 8.2 有声故事书（200 条程序化生成）
- 数据文件：`src/data/stories.ts`，10 动物×20 地点确定性生成 200 条，ID `gen-001..200`（story_progress 兼容）；每条约 3 段+3 题，问题/答案/干扰项随参数生成，障碍句按 index 轮换
- `StoryTempleView.vue`：页面每次**随机显示 5 条**；`refreshStories()` 抽 5 条并**避开上一批**（池子不足 5 回退全量），onMounted 初始化
- 刷新按钮 🔄 换一批 位于"📚 有声故事书"section-title 右侧（`.section-title-row` 布局）
- 答题时隐藏故事文本（`.story-text-box` `v-show="!showQuestion"`）
- 答对一题 **+3 星**（原 +5），`coins.addCoins(3,'回答故事问题正确','story_temple')`，反馈文案同步
- **TTS 卡死修复（2026-08-17）**：微信/X5/Android WebView 的 `speechSynthesis.onend` 可能永不触发 → `isPlaying` 永久 true、按钮不可点、无法停止。修复：①`resetSpeech()` 用 `cancel()+pause()+resume()` 重置 Chromium 卡死状态（speak 前/停止/答题/退出统一调用）②安全兜底定时器 `text.length*260+2500ms` 未触发 onend/onerror 则强制进入问题环节 ③播放中新增「⏹ 停止」按钮（`.play-btn.stop` 粉红渐变）随时停止 ④无 `speechSynthesis` 或空文本时 800ms 后直接出题

## 8.4 忘记密码（OTP 验证码重置）
- 页面 `src/views/auth/ForgotPasswordView.vue`，路由 `/auth/forgot-password`（无 requiresAuth，guard 不拦截）
- 3 步：邮箱（支持 `?email=` 预填，来自切回家长弹窗的 `attention_planet_parent_email`）→ 8 位验证码（**单个普通输入框** `maxlength=8`+过滤非数字，回车可验证，不足 8 位置灰；非注册页的拆分 OTP 框）→ 新密码+确认
- 复用 `auth.sendLoginOtp`（`signInWithOtp`+`shouldCreateUser:false`，未注册邮箱报错）/ `verifyOtp` / `setPassword`
- **入口**：登录页密码框下「忘记密码？」链接；HomeView 切回家长弹窗密码框下「忘记密码？」按钮（关闭弹窗→跳转并预填家长邮箱）
- 成功：`setPassword` → `auth.logout()` → 成功页「返回登录」→ `/auth/login`（用户确认：重置后跳登录页重登，不直接进首页）
- **同密码校验**：Supabase `updateUser` 拒绝新旧密码相同（"New password should be different from the old password"），已转中文提示「新密码不能与旧密码相同，请换一个」
- **坑**：OTP 验证后已登录为家长，此时点「去登录」会被路由守卫重定向 `/home`；`goLogin()` 先 `auth.logout()` 再跳转解决
- `auth.logout()` 加固：`signOut()` 若因网络抛错可能残留本地 session → 新增 `clearStaleSession()` 强制删 `localStorage` 的 `sb-<ref>-auth-token`（supabase-js `getSession()` 从 localStorage 读取，清后守卫即失效）
