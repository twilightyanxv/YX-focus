# 注意力星球 · 项目上下文

> 最后更新：2026-08-15

## 1. 概述 / 技术栈
面向 5-12 岁儿童的游戏化专注力训练 PWA。家长建家庭、添加/管理孩子、发奖励；孩子训练赚星币、商店消费。
Vue3+TS+Vite+Pinia+VueRouter4(Hash)+Supabase+CSS动画+Canvas+vite-plugin-pwa。Node v24 Windows。构建验证：`npx vue-tsc --noEmit` + `npx vite build`。

## 3. 认证 / 角色
- **家长**：OTP 注册（1 封邮件/家庭）→ verifyOtp → 设密码。OTP 框 8 位兼容 6/8；Supabase 需关 Confirm email。
- **孩子**：家长面板输入昵称（≤10 字，双端校验）→ Edge Function 创建；随机邮箱 `child_xxx@tmp.attentionplanet`+随机密码存 `profiles.child_password`；0 邮件。孩子注册入口已注释。
- **切换**：`switchToChild`（EF 返回 session）/ `switchBackToParent`（需家长密码）。家长 session 存 localStorage：`attention_planet_parent_session` / `attention_planet_parent_email`。`isSwitchedToChild()`= parentSession 存在 或 孩子且 parent_id 存在。
- 家庭邀请码：6 位纯数字。

## 4. Edge Function：create-child-user
`supabase/functions/create-child-user/index.ts`，esm.sh 导入，CORS+OPTIONS，家长 JWT 验证（不 --no-verify-jwt），需 Secret `SUPABASE_SERVICE_ROLE_KEY`。
body 模式：`{nickname}` 添加 / `{child_id}` 切换 / `{delete_child:true,child_id}` 删除 / `{lookup_parent_email:true,child_id}` 查家长邮箱。
**每次改动需在 Dashboard 手动重新部署**。CLI 备用：`C:\Users\言绪\AppData\Local\supabase-cli\supabase.exe`（已入 PATH）。

## 5. 数据库
迁移：`supabase-migration.sql`（部分需手动执行）。
- 表：`profiles`(含 child_password) / `focus_sessions` / `detective_scores` / `story_progress` / `rhythm_scores` / `star_coin_log` / `items` / `user_items` / `parent_rewards` / `redemption_requests` / `donations`(支持记录，user_id+method alipay/wechat) / `feedbacks`(意见反馈，content≤200)
- security definer 函数：`get_total_coins(user_id)`（本人或家长可查）、`refund_coins(child_id,amount,reason)`（家长拒绝兑换返还）
- `detective_scores.game_type` 约束已扩为 `('schulte','stroop','whack')`；打地鼠复用本表，家长看板"侦探次数"自动计入
- RLS：用户读写自己数据；家长可读孩子（profiles/各成绩表/redemption_requests/parent_rewards/donations）

## 6. 星币系统（重要修复）
- 禁用乐观更新/Realtime 累加，统一 `fetchTotalCoins()` 拉绝对值（幂等防 double-count）
- `coins.ts`：`syncForUser()` 切换用户重新拉取+重订阅；realtime 频道按 user_id 缓存；App.vue watch `auth.user?.id`

## 7. 专注花园
`src/views/focus-garden/`：`FocusGardenView.vue` 选种→时长→种植→写 focus_sessions，页面加载从 DB 恢复；`GardenPlanting.vue` 全屏专注：
- 时长选项：**5/10/15 分钟**（1 分钟已移除，默认 5 分钟；coins 3/10/20/35 中已无 3）
- 无走开检测；每 20-40s 弹数学题（4 选项）；浇水互动（💧+弹跳）；5 里程碑（20/40/60/80/100%）toast+光环+粒子；氛围金粒子；🐝🦋 随机飞过；完成金色闪光
- `usePlantGrowth.ts`：茎 5~65%、叶 28~58%、花 50~90%
- 4 植物 CSS 分解生长动画：SunflowerPlant/CactusPlant/RosePlant/StarflowerPlant；花瓣绕花心旋转贴合；茎 10px；玫瑰叶 leafGrow 展开

## 8. 打地鼠（侦探训练营第 3 游戏）
`src/views/detective-camp/WhackAMole.vue`，路由 `/detective-camp/whack`
- 3×3 地洞，地鼠🐹80%/炸弹💣20%，60s 限时；打地鼠固定 +10（无连击加成），打炸弹−15+清连击+抖动，逃走无惩罚
- 洞：深色 `hole-mouth`(z1)+`target-wrap`(z2, overflow hidden 裁缩回)，无 lip；地鼠 flex 居中，bottom −58→8px 冒出
- 锤：CSS 木锤（头下柄上），支点 `50% 0%` 位于洞右 `calc(50% + 106px)`、`top:47px`（106=柄88+头半18，90° 时正中地鼠）；动画 `180°→88°命中→93°→90°淡出`（逆时针 12→9 点）
- 音效：Web Audio 合成（地鼠上行双音/炸弹低音/逃走噗声），`ensureAudio()` 开始游戏时初始化
- 星币：`<300→0 星`；`≥300 → floor(score/100)-2`（300-399→1，400-499→2…）；0 星不写流水，结算页提示
- 成绩落库：`game_type='whack'`, score/accuracy/reaction_time_ms
- `.game-area` 上下居中（min-height:70vh+flex column+justify-content:center）

## 8.2 有声故事书（200 条程序化生成）
- 数据文件：`src/data/stories.ts`，10 动物×20 地点确定性生成 200 条，ID `gen-001..200`（story_progress 兼容）；每条约 3 段+3 题，问题/答案/干扰项随参数生成，障碍句按 index 轮换
- `StoryTempleView.vue`：页面每次**随机显示 5 条**；`refreshStories()` 抽 5 条并**避开上一批**（池子不足 5 回退全量），onMounted 初始化
- 刷新按钮 🔄 换一批 位于"📚 有声故事书"section-title 右侧（`.section-title-row` 布局）
- 答题时隐藏故事文本（`.story-text-box` `v-show="!showQuestion"`）
- 答对一题 **+3 星**（原 +5），`coins.addCoins(3,'回答故事问题正确','story_temple')`，反馈文案同步

## 8.3 反转任务（侦探训练营第 4 游戏，原在故事神殿）
- 从 `StoryTempleView.vue` 迁出为独立页 `src/views/detective-camp/ReverseTask.vue`，路由 `/detective-camp/reverse`
- 听 4 个动作（语音+文本展示，3s 倒计时）→ 倒序点击身体部位；全部正确 +5 ⭐（`coins.addCoins(5,'完成反转任务','detective')`），失败显示正确答案
- 不落库成绩；`onUnmounted` 清理语音/定时器
